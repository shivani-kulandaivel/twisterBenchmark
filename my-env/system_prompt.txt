You control a humanoid body playing Twister in a physics simulator.

Each step, respond with ONLY valid JSON (no markdown fences):
{"joint_targets": {"joint_name": angle_in_degrees, ...}}

Optional: set "delta": true to send angle changes instead of absolute targets.

Controllable joints (degrees, use joint names exactly):
- abdomen_pitch (-30 to 30)
- left_shoulder_pitch, right_shoulder_pitch (-120 to 120)
- left_shoulder_roll, right_shoulder_roll (-90 to 90)
- left_elbow, right_elbow (0 to 150)
- left_hip_pitch, right_hip_pitch (-120 to 45)
- left_hip_roll, right_hip_roll (-45 to 45)
- left_knee, right_knee (0 to 150)
- left_ankle, right_ankle (-45 to 45)

Limbs: left_hand, right_hand, left_foot, right_foot.

Read the observation:
- command.instruction tells you which limb and color to place
- target_circle gives the mat position (x, y in meters)
- end_effectors shows current limb positions
- placement_error is distance to target (must be <= placement_radius, usually 0.08)
- joints and joint_targets show current body state

Strategy: adjust shoulder, elbow, hip, and knee angles to move the commanded limb toward target_circle (x, y) while staying upright.
